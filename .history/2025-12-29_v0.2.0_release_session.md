## Feature Summary

### 1. Rate Limiting (Issue #1)
- Three-tier rate limiting: auth (5/min), streaming (10/min), API (100/min)
- Configurable via environment variables
- X-RateLimit-* headers

### 2. Query Analysis (Issue #2)
- Multi-intent detection (8 intent types)
- Query decomposition for compound queries
- Confidence scoring (0.0-1.0)
- Query rewriting and expansion

### 3. Full-Text Search (Issue #3)
- PostgreSQL full-text search with tsvector
- BM25-style scoring
- Phrase, boolean, and fuzzy search modes
- Hybrid ranking with RRF

### 4. HITL Workflow (Issue #4)
- Confidence-based routing (auto-approve ≥0.9, quick review ≥0.7, detailed <0.7)
- Batch approve/reject operations
- Quality metrics dashboard
- ML feedback signals

### 5. CLI Ingestion (Issue #5)
- Directory watch mode with notify
- Progress bars with indicatif
- Parallel processing (configurable workers)
- Checkpoint/resume support
- Dry-run validation

### 6. Ontology Management (Issue #6)
- Schema versioning (semver)
- Entity/relation type definitions
- Import/export: JSON, YAML, OWL 2, RDF Turtle
- Schema migration and diffing
- Backward compatibility checks

### 7. Advanced Caching (Issue #7)
- Two-tier: L1 in-memory (moka) + L2 Redis
- Cache types: embeddings, rankings, graph traversals
- Cache warming strategies
- TTL + LRU invalidation
- Comprehensive metrics

### 8. Document Management (Issue #8)
- Document versioning with content diff
- Bulk upload/delete (up to 100 docs)
- Auto-tagging and language detection
- Collections/folders with ACL
- Soft delete with retention policies
- Processing lineage tracking
