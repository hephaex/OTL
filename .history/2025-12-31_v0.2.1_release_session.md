## Notes

### vLLM Configuration
vLLM uses OpenAI-compatible API, so configuration requires:
- `LLM_PROVIDER=openai` (not `vllm`)
- `OPENAI_API_BASE=http://<vllm-server>:8000/v1`
- `OPENAI_API_KEY=dummy-key-for-vllm` (any non-empty value)

### GHCR Authentication
Required Classic PAT with `write:packages` scope for docker push to ghcr.io.
